# xiezhi

A small Python (FastAPI) service built to practice secure-by-design engineering end to end: container, CI security gates, Kubernetes, infrastructure as code, keyless deploys, secure API design and detection.

Named after the 獬豸 (xiezhi), the mythical creature that tells right from wrong.

## Design notes

Grows with the build: data flow, trust boundaries, threats (STRIDE) and the control for each.

- **Dependencies:** every runtime package (including transitive ones) is locked to an exact version and hash (`requirements.txt`, generated by `pip-compile --generate-hashes`); the image installs with `--require-hashes`, so what was audited is exactly what ships.
- **Container:** base image pinned by digest; runs as a dedicated non-root user with a numeric UID; build context limited by `.dockerignore`.
- **Surface:** interactive API docs (`/docs`, `/redoc`, `/openapi.json`) are disabled.

## Run locally

```bash
python -m venv .venv && source .venv/Scripts/activate   # Windows Git Bash
pip install --require-hashes -r requirements.txt
pip install -r requirements-dev.txt
pytest
uvicorn app.main:app --reload
```

To change dependencies, edit `requirements.in` / `requirements-dev.in` and re-run `pip-compile` (see the headers of the generated files).
